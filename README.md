# BankVault Web Application
A banking simulation web application developed using Python and Streamlit.

# Features
- User Registration
- Secure Login
- Dashboard
- Fund Transfer
- Account Statement

# Technologies
- Python
- Streamlit
- Object-Oriented Programming

# Live demo
- https://bankvault-app-krutika.streamlit.app/

pip install -r requirements.txt
